# Agent Fleet Desktop 2.7.0

Ngày 07/11/2026. Tiếp nối [2.6.1](2.6.1.md), triển khai giao diện **Calm Workspace** dễ đọc, biểu đồ token theo ngày đầy đủ, tuỳ chọn diện mạo lưu qua Desktop và thu gọn file diff thực sự.

- **Nền thị giác Calm Workspace**: Mặc định nền trắng thuần (`#FFFFFF`), chữ slate (`#334155`/`#64748B`), màu nhấn xám xanh dịu (`#4B648C`/`#EEF3FA`), trạng thái thành công/cảnh báo/lỗi đạt chuẩn tương phản WCAG AA; tiêu đề trang đồng nhất một màu, dùng `tabular-nums` cho toàn bộ số liệu thống kê.
- **Tuỳ chọn Diện mạo (`Appearance`) & lưu bền vững trên Desktop**: Menu `Diện mạo` trên thanh công cụ cho phép chọn nền sáng (`Trắng (mặc định)` / `Giấy ấm`), phông chữ (`Segoe UI` / `Inter` / `Bricolage` kèm câu mẫu tiếng Việt), cỡ chữ (`15px` / `16px`) và chuyển động (`Theo hệ thống` / `Giảm` / `Tắt`), đồng bộ qua bridge native `fleet:set-appearance`.
- **Biểu đồ Token 7 ngày (`DailyTokenChart`)**: Bổ sung chuỗi dữ liệu 7 ngày theo lịch máy cục bộ (`buildDailyTokenSeries`), phân biệt rõ ngày không có lần chạy, lần chạy chưa báo cáo token (`null`) và giá trị `0`; có nhãn thứ + `dd/MM`, đánh dấu `Hôm nay`, tooltip chi tiết Input/Output và chế độ xem bảng dữ liệu 7 dòng hỗ trợ bàn phím. Không còn ẩn biểu đồ khi cửa sổ thấp (`1280×640`).
- **Tách 4 thẻ CLI độc lập & Tập trung thẻ (Spotlight)**: Tách 4 vùng CLI thành 4 card riêng có bo góc và khoảng cách rõ ràng; hỗ trợ chế độ Tập trung thẻ cho cả 7 card trên Dashboard (nhấn nút tập trung, chuyển tiêu điểm khi Tab sang thẻ khác, thoát bằng `Esc` hoặc nhấn ra ngoài mà không làm mờ chữ hay chặn nút con).
- **Thu gọn Diff thực sự & Hệ thống Motion**: Chuyển nền/viền về từng `.diff-section`, đóng file dùng Web Animations API và gỡ bỏ dòng DOM khi hoàn tất để xoá vùng xám trống; trạng thái nút `Kiểm tra` / `Kiểm tra tất cả` phản ánh chính xác kết quả `lastCheck.status` (`ready`, `needs-login`, `unavailable`, `unknown`, `error`), kèm ẩn cửa sổ console phụ trên Windows khi spawn tiến trình con.

Kích thước: thư mục portable 146,6 MiB (`appMiB: 7,07`, 75 package runtime), zip 80,5 MiB (`84.462.168` byte). Mục tiêu tổng gói portable <115 MB vẫn **chưa đạt** do đóng gói kèm Node và .NET self-contained.
